# Answers after a reveal count as recall

Decided 2026-11-05 by the user (MF-0027, Q-1: "Count it"). Every mode shows the key after a graded answer: the Duel shows the rationale for every option, and the Daily Walk, seed checks and storm review show the key too. A learner who meets the same question again can answer from memory of that reveal. Such a correct answer counts toward the forest like any other recall, with no discount and no change to the FSRS rating.

The reason is that feedback after a retrieval attempt is part of spaced retrieval: the learner tried, was graded, then saw why. That differs from **Spoiled** (MF-0007), where reviewing a question shows the key before the learner has retrieved anything, so their later attempts on it never count. The two rules stay separate: Spoiled is a key seen without an attempt, and **Revealed** is a key seen as feedback on one (CONTEXT.md).

We rejected three alternatives. Dropping a correct answer whose key was shown within N days would stall CCDV-F: with 2 questions per skill, a daily player meets the same question every second serve, so most attempts after the first pass would be discarded. Replaying those answers as FSRS `Hard` still needs an N and only slows growth. Skipping recently revealed questions in the pickers does little with 2 or 3 questions per skill.

**Consequences:** on small banks the forest can overstate exam readiness, because a learner can grow a skill by remembering a few keys. Memory is per skill (`memoryBySkill`), and the pickers serve the least recently seen question, so on CCDV-F (2 or 3 questions per skill on 2026-11-05) the same question returns every second or third serve. Probed on ts-fsrs 5.4.2 with fuzz off, a wrong answer on day 0 followed by correct answers to revealed keys on days 2, 6, 14 and 30 gives stability 2.43, 9.69, 24.0 and 50.0 days. That passes the Tree and Ancient thresholds, which still need a storm proof, and storms draw from the same bank. The mitigation is bank size (a covered skill has 15 questions, goal G3), not a grading penalty. Revisit this ADR if banks stay below that size close to an exam, or if storm scores and forests diverge for the same learners.
