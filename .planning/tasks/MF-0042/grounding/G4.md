## Drift (course → today's docs)

- **Claude Code SDK → Agent SDK.** A links a "Migration guide … migrate from the Claude Code SDK packages to the
  Agent SDK"; H's title line reads "Use the Agent SDK to run Claude Code programmatically from the CLI, Python, or
  TypeScript." Items use "Agent SDK"; the D3.S3 card names the old term once.
- **`-p` loads the project's configuration unless `--bare`.** H: "`--bare` is the recommended mode for scripted and
  SDK calls, and will become the default for `-p` in a future release." Items teach `--bare` for CI.
- **`-p` permission default.** H: "With Claude Code v2.1.302 or later, `claude -p` runs start in Manual mode when
  nothing sets a permission mode." The card's first break relies on this.
- **"Explore, plan, code, commit" as a named recipe.** Today's BP no longer presents that four-step recipe; it is

  new codebases"), plan (CW "Plan before editing"), verify (BP "Give Claude a check to run"), commit (CW "Create pull
  requests"; BP "a person approving the merge"). It adds the verify step the old recipe lacked.
- **"think hard / think harder" keywords.** BP: those phrases "are ordinary prompt text that nudges Claude within its
  effort setting rather than keywords that raise it. `ultrathink` still works". Not used in G4 items; flagged for
