## Drift (course → today's docs)

- **Remembering with `#`.** Older Claude Code (and the course era) added a memory line by starting a message with
  `#`. Today's memory page documents no `#` shortcut: asking Claude to remember saves to **auto memory**, and you add
  to CLAUDE.md by asking ("add this to CLAUDE.md") or via `/memory` (D2.S1 q3).
- **Thinking keywords.** The course taught prompt keywords ("think", "think hard", "ultrathink"). The D2.S2 sources
  (common-workflows, interactive-mode, permissions) contain neither `ultrathink` nor "think hard" (grep, 0 hits);
  interactive-mode documents the `Option+T`/`Alt+T` toggle and says it has no effect on Opus 5.5, Sonnet 5.5,
  Haiku 5.5 or Fable models, which always use extended thinking. Fork T5 reports best-practices says "think hard"
  is now ordinary text and only `ultrathink` still works; D2.S2 items use only the toggle text (q4) and make no
  keyword claim.
- **Install.** The course installed with `npm install -g @anthropic-ai/claude-code`; today the native installer is
  "Recommended" and auto-updates, npm remains supported (Node.js 22 or later) and `claude doctor` is the check.
  No item asserts an install method (q1 tests verify/diagnose only).
- **Permission modes.** Today's cycle includes `auto` (a classifier) and labels `default` as "Manual"; a course
  showing only default / acceptEdits / plan is out of date (D2.S2 diagram).
- **AGENTS.md.** Today Claude can read a repository's AGENTS.md in place of CLAUDE.md (HC, ME); not tested here.
